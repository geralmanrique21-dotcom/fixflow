FIXFLOW — PROTOTIPO FRONT-END
Archivos principales: index.html, styles.css, script.js.
Logo: assets/fixflow-logo.png contiene el logotipo original suministrado. Se muestra con object-fit: contain y proporción 3:2, sin recortes ni deformación.
Fondo: arquitectura oscura sobria con motivos tecnológicos discretos (nodos de automatización, referencias n8n y fragmentos de código).
Interacciones: botones, pestañas, enlaces e inputs tienen realce al pasar el cursor y estados de foco para teclado.
Prueba local: abre index.html en un navegador.
Publicación: sube todos los archivos y la carpeta assets a GitHub y conecta el repositorio con Vercel. Framework Preset: Other; proyecto estático.
Nota: formularios demostrativos, sin backend, autenticación real ni base de datos.
